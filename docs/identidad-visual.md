# Identidad visual

Elegida el 03/11/2026: paleta **Lavanda y blanco** con la fuente **Nunito**. Los colores están como variables al principio de `frontend/src/estilos.css`; para cambiar uno, se cambia ahí.

| Uso | Color |
| --- | --- |
| Fondo | `#F8F6FC` |
| Tarjetas | `#FFFFFF` |
| Lila suave (pastillas, fondos de íconos) | `#ECE6FB` |
| Principal (botones, links, logo) | `#7C5CE0` |
| Texto | `#26213A` |
| Texto secundario | `#6B6585` |
| Líneas y bordes | `#E7E2F2` |
| Aviso de perdida / errores | fondo `#FCE0DC`, texto `#B3362A` |

Estilo: bordes redondeados (12 px en campos y botones, 20 px en tarjetas), botones llenos en violeta y secundarios con borde, sombras suaves. Pensado primero para celular, porque la ficha pública se abre al escanear la placa en la calle.
